# 宮本琉太 ポートフォリオ

福岡大学 法学部の宮本琉太のポートフォリオサイト。Next.js（Pages Router）の1ページ構成。

## 構成

- `pages/index.js` — 共通レイアウト（見出し・カード・開閉・スクロール表示など）。文章は持たず、`content/active.js` から読み込んだデータを描画する。
- `content/normal.js` — 通常版の文章データ（このリポジトリで管理する版）。
- `content/active.js` — ビルドで使う版を指定する。既定は通常版。
- `styles/globals.css` — スタイル。
- `next.config.js` — `output: 'standalone'`（ロリポップ！デプロイナウ用）。

文章はすべて `content/` に分けてあるので、レイアウトを変えずに内容だけ差し替えられる。
別の版を作るときは、ビルド用の作業フォルダで `content/active.js` だけを差し替えて同じレイアウトをビルドする。
別の版の文章データはこのリポジトリには置かない（公開リポジトリには通常版だけを置く方針）。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番ビルド
```
